# Biglietto di compleanno Martina

Contiene un solo file: `index.html`.

## Pubblicarlo gratis con GitHub Pages
1. Vai su GitHub e accedi.
2. Crea un nuovo repository, per esempio `martina-birthday`.
3. Scegli `Public`.
4. Carica il file `index.html` nella cartella principale del repository.
5. Apri **Settings** del repository.
6. Vai su **Pages**.
7. In **Build and deployment**, scegli **Deploy from a branch**.
8. Seleziona branch `main` e cartella `/ (root)`.
9. Salva.

GitHub mostrerà l'indirizzo pubblico del sito nella stessa pagina Pages.
